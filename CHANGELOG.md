# Changelog

## 1.0.0

- First release of **Life** as a browser game (replaces the gol-rs terminal toy).
- Title, sandbox, ten-challenge campaign, and daily soup.
- Conway / HighLife / Seeds / Day & Night in sandbox.
- Typed-array engine with optional wrap, live-cell hash, RLE and share links.
- Detectors for still lifes, period-2 oscillators, gliders, and LWSS.
- Canvas glow renderer, muteable WebAudio ticks, localStorage stars and scores.
